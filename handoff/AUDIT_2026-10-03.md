## Root cause and code-quality findings

1. `renderFullPlayer()` writes `palette.signal`, while `getArtworkPalette()` has no `signal` member.
2. `syncAppearance()` later overwrites metadata on initial open, hiding the defect in some modes; mode changes expose it.
3. Commits claiming a single metadata writer did not land the relevant `src/app.js` source.
4. `runtimeQualityGuard.js` tries to repair rendered DOM with a document-wide observer; its placeholder regex is double-escaped and ineffective. Even repaired, this would be the wrong ownership boundary.
5. Candidate architecture layers canonical Discover behavior and playback contexts on top of a large legacy monolith through DOM/event observers. Tests cover important contracts, but this is prototype compatibility debt, not production architecture.
6. `src/ui/discoveryHub.js` is minified source committed directly and coexists with dormant `renderDiscoverView()`. Consolidate only after the accepted experience is integrated.
7. Release chapters are state-backed; standalone deep-link behavior remains unproven.
8. Main's Pages workflow deploys the repository root and has no test dependency; candidate QA lives only on its feature branch. A production pipeline must gate deployment on current tests and dependency policy.

## Product assessment

The strongest product idea is not “more music features”; it is a clear listening mental model: find quickly, play without losing place, explore intentionally, and keep meaningful context. Separate resumable Global and Journey sessions, truthful credits/provenance, artist worlds, saved moments, and calm queue control can differentiate Rondo if implemented natively rather than through patches.

Current weaknesses are prototype debt, not lack of ideas: duplicate renderers, a monolith plus observer-based compatibility layers, local-only identity, fake/demo catalog constraints, incomplete empty/error/rights states, and no production ingestion/search/account/authorization foundation. Adding real content before correcting these boundaries would multiply rework.
