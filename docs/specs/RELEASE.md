# Spec: Release page (Album / EP / Single)

Status: approved D-076 (2026-10-07: "i like the stuff you added"), Home E rev 13; rev 13.1 simplifies per D-077 (song credits in the ⋯ menu). Desktop + phone.

**Character:** the back of a record sleeve. Albums are made to be heard front to back, so this page leans into that instead of being another list.

## Opens from

Artist page (release cards and Latest release card — the round play button still just plays), "More from <artist>" on another release, Stage "Go to album / EP / single". Opening never changes playback.

## Layout

1. **Header** tinted by the cover: cover with the **record behind it** — it peeks out on hover, slides out when this release is playing and spins only while audio plays (reduced motion: no spin, no slide). "New" badge for this week's releases, type · year, title, artist link (round photo), songs · time · label.
   Actions: **Play** (state-aware; starts at song 1 and turns shuffle off — "Plays in order, front to back"), **Save** to library (Undo), ⋯ (Start radio, Add to queue, Go to artist, Share).
   Meta line: plays-in-order note, heard progress bar ("3 of 7 heard" / "You've heard every song"), Journey chip ("Hip-Hop Journey · stamp collected" → Artist Journey).
2. **Tracklist** — 7+ songs split into **Side A / Side B**; row: big mono number (eq when playing), title, feat. artists, ✓ if heard, time, ⋯ song menu with **Show credits** (expands Written by / Produced by / Mixed by / Tempo · key, with a close button; rev 13.1, D-077 — no per-row chevron). Row click plays from that song in release order. Footer: year · songs · time.
3. **Liner notes** — Released, Label, Written by, Produced by (tap = play their credits), Mixed by, ℗ line. Only catalog facts.
4. **More from <artist>** + Go to artist.

## Phone

Back link, stacked header (cover ≈ 60 % width, record peeking), compact rows (no time column), credits 2-up.

## Later

Disc 2 / bonus tracks, release-day countdown (A6 pre-save), artist's note on the release (A5 artist tools, V2), lyrics/credits for the whole record as one page, vinyl/merch links (not planned).
