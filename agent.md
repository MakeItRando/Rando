# Agent entry point

The canonical operating instructions are in [`AGENTS.md`](AGENTS.md).

Any agent starting work must also read, in order:

1. [`handoff/STATE.md`](handoff/STATE.md)
2. [`handoff/HANDOFF_REPORT.md`](handoff/HANDOFF_REPORT.md)
3. [`handoff/DECISIONS.md`](handoff/DECISIONS.md)
4. [`handoff/PRODUCT_MAP.md`](handoff/PRODUCT_MAP.md)
5. [`handoff/QUALITY_GATES.md`](handoff/QUALITY_GATES.md)

Do not implement or merge from this pointer alone.
